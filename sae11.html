SAÉ11

Sensibilisation à l’hygiène informatique et à la cybersécurité

Contexte

Dans le cadre de cette SAÉ, j’ai travaillé sur la sécurisation d’un accès SSH sur une machine Debian. L’objectif était de comprendre le fonctionnement du protocole SSH ainsi que les différentes méthodes permettant de renforcer la sécurité d’un accès distant.

Problème rencontré

Après avoir modifié le port SSH par défaut afin d’améliorer la sécurité, la connexion distante ne fonctionnait plus et le message Connection refused apparaissait.

Analyse du problème

Après analyse, j’ai compris que le client SSH tentait toujours de se connecter sur le port 22 par défaut, alors que le serveur utilisait désormais le port 2222.

Résolution

Pour corriger ce problème, j’ai utilisé l’option -p dans la commande SSH afin de préciser manuellement le nouveau port :

ssh -p 2222 utilisateur@adresse_ip

Il suffit ensuite de saisir le mot de passe de l’utilisateur pour établir la connexion SSH.

Compétences acquises

  • Compréhension du protocole SSH
  • Configuration d’un serveur OpenSSH
  • Gestion des ports réseau
  • Sécurisation d’un accès distant
  • Analyse et résolution d’erreurs réseau
